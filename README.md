# La Scarpetta Ochtrup – Website-Konzept

Ein unverbindliches, modernes Website-Konzept für das Ristorante Pizzeria La Scarpetta in Ochtrup.

## Lokal starten

```bash
npm start
```

Danach unter `http://127.0.0.1:4391` öffnen.

## Enthalten

- Fünf eigenständige Seiten
- Deutsch, Niederländisch und Englisch
- Interaktive Speisekarte mit Tavolata-Planer
- Intelligente Reservierung mit Datum, Verfügbarkeit, Sitzbereich und Anlass
- Originalbilder und Originalbranding
- Impressum und Datenschutz-Konzept
